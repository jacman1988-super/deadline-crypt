Deadline Crypt - real Kiro development evidence
31 October 2026

The entrant explicitly requested a cash-prize contest planner with reminders, missing materials, cash separate from credits and registration separate from submitted work.
Codex prepared the brief and tool profile; native official Kiro CLI 2.37.0 on the Free plan performed two real implementation runs. No paid API key, shell or MCP tool was provided to Kiro. It used fs_read/fs_write only.
Run 1 created the initial app, domain logic, CSS, specs, steering and tests. Codex executed the tests and real browser checks. Run 2 corrected the observed failures from review-feedback.txt.
Codex then materially refined presentation, import/schema edge cases, demo fixtures, backup history merging, storage recovery, accessible focus and confirmation controls. The final project is a collaboration, not a claim that Kiro alone authored the final files.
The repository agent profile is portable. Its original local counterpart had absolute paths restricted to the project directory; the private original is kept outside this repository. These paths are autoapproval rules, not a claimed OS sandbox.
